I need to abandon the EV-weighted gate approach entirely. The sigmoid(best_pnl * scale) creates soft targets that are mostly near 0 for losing trades, which dominate the dataset. This overwhelms the pro-trade bias and pushes the model toward never trading. Instead, I'll return to a simpler binary classification approach: if ANY option strike has positive stopped P&L, the target is TRADE=1, otherwise NO_TRADE=1. I'll also reduce the magnitude weighting impact and increase the learning rate to help the model escape the zero-trade attractor more quickly.
