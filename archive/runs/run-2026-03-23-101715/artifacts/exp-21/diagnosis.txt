The model is experiencing zero-trade collapse in almost all experiments (19/20 scoring -10.0), indicating it's learning "never trade" despite the pro-trade gate bias. The single biggest weakness is that the EV-weighted gate loss with sigmoid targeting creates a "don't trade" attractor - when best_pnl is negative (which happens often), sigmoid(negative_pnl * scale) approaches 0, strongly reinforcing NO_TRADE behavior. The few experiments that did trade (#16, #17) had terrible chunk consistency (worst_chunk_pf < 0.50), suggesting the model trades randomly when it does trade.
