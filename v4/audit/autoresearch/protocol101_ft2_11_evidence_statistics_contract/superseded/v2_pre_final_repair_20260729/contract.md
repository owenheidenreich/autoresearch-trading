## 6. Dependence And Bootstrap Validity

The market session is the dependence cluster. Minutes, contracts, decisions,
and trades are never independent market observations.

### 6.1 Corrected effective sample size

ESS uses Geyer's initial-positive-sequence long-run-variance estimator within
each fold.

For a chronological session statistic:

```text
gamma_k = (1/n) sum_t (x_t - xbar)(x_(t+k) - xbar)
Gamma_m = gamma_(2m) + gamma_(2m+1)
```

Consecutive positive `Gamma_m` pairs are retained and forced monotonically
nonincreasing. The sequence stops at the first nonpositive pair. It does not
stop because one individual autocorrelation is nonpositive.

```text
LRV = max(gamma_0, -gamma_0 + 2 * sum(adjusted retained Gamma_m))
ESS = n * gamma_0 / LRV
```

Finite ESS is clamped to `[1,n]`. Fold ESS values are summed for pooled
diagnostics. Dependence is never estimated across fold boundaries.

### 6.2 Block-length sensitivity

All hard evidence uses noncircular moving blocks at lengths:

```text
{3, 5, 8} sessions
```

Blocks are contiguous, remain inside one fold, never wrap, and never cross a
fold boundary. For hard decisions:

- adjusted lower bound = minimum across block lengths;
- adjusted upper bound = maximum across block lengths; and
- adjusted p-value = maximum across block lengths.

An uncomputable required length with otherwise valid data is
`insufficient_evidence`.

### 6.3 Adjusted upper bounds

For each synchronized centered bootstrap replicate:

```text
max_lower_b = max_h(t*_h,b)
max_upper_b = max_h(-t*_h,b)
```

The nearest-rank 0.95 quantiles give lower and upper critical values.

```text
LCB_h = observed_mean_h - c_lower * SE_h
UCB_h = observed_mean_h + c_upper * SE_h
```

These matched simultaneous bounds make no-signal and harm terminals decidable.

### 6.4 Synthetic coverage prerequisite

Before any market evidence packet, the implementation must demonstrate
coverage on frozen synthetic AR fixtures with:

- `phi` in `{-0.3, 0.0, 0.3, 0.6, 0.8}`;
- means `0.0` and `0.25`;
- one 45-session fold and five independent 45-session folds;
- block lengths `{3,5,8}`;
- fixed hash-derived seed;
- 2,000 Monte Carlo series per fixture; and
- 2,000 bootstrap replicates per series.

Each one-sided lower and upper fixture requires empirical coverage at least
0.93 and Wilson 95% lower coverage at least 0.90. Failure invalidates the
inference implementation before it touches market evidence.
