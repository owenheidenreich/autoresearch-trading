# Transition Completion Criteria

Purpose: define what "done" means for the migration from an improvisational
project to an AI-agent-controlled research organization.

The transition is complete when `research_ops/CEO_DASHBOARD.md` alone answers:

1. What is the current operational default?
2. What is frozen?
3. What is blocked?
4. What is the current P0 assumption?
5. What evidence was collected last?
6. What changed in the last iteration?
7. What does the verifier object to?
8. What decision needs to be made?
9. What is the next Codex prompt?

This is a governance completion test, not a trading-edge completion test. The
transition can be complete while paper-submit trust, execution realism,
replay/live parity, lifecycle parity, validation provenance, and model promotion
remain blocked.

## Required Dashboard Sections

`CEO_DASHBOARD.md` must include:

- `Current Operational Default`
- `Frozen Control`
- `Current Safety Posture`
- `Active Iteration`
- `Latest Completed Iteration`
- `What Changed In The Last Iteration`
- `What The Verifier Objects To`
- `Decision Required Now`
- `Current P0 Assumption`
- `All P0 Assumptions`
- `Blocked Actions`
- `Evidence Collected Last`
- `Newly Falsified Assumptions`
- `Next Recommended Codex Prompt`
- `Transition Completion Check`

## Failure Conditions

The transition is not complete if:

- The dashboard does not identify `PAPER_DEFAULT_PROTOCOL101`.
- The dashboard does not identify the frozen Protocol101/Protocol051/Protocol066_081 control.
- The dashboard omits blocked actions around promotion, training, thresholds,
  runtime flags, launchd, broker behavior, paid data, or protected holdouts.
- The dashboard cannot name the active or latest completed iteration.
- The dashboard cannot name the latest evidence and verifier objections.
- The dashboard recommends strategy/model work before execution-and-parity
  falsification.
- The dashboard points to stale docs instead of research_ops state and iteration
  artifacts.

## Completion Statement

When the dashboard passes this checklist, the project has a research-operations
control tower. The next work should proceed as scoped iterations, not ad hoc
improvements.
