# Glossary

Last updated: 2026-05-24

| Term | Meaning |
|---|---|
| Control | The frozen baseline used for comparison. Current control tag: `v4-protocol101-control-2026-05-24`. |
| Operational default | The system that is allowed to run by default. Current value: `PAPER_DEFAULT_PROTOCOL101`. |
| Challenger | A research-only candidate that has not passed the promotion gate. |
| Cartography report | A read-only map of code, data, docs, artifacts, and operational truth. |
| Experiment RFC | A pre-results proposal defining hypothesis, assumptions, method, metrics, and falsifiers. |
| Implementation summary | A record of what changed, why, and how protected surfaces were avoided. |
| Verifier report | An independent check of a claim, artifact, or patch. |
| Decision memo | A binding accept/reject/defer/freeze/promote decision. |
| CEO packet | A dashboard-level summary for human routing, not primary evidence. |
| Replay/live parity | Evidence that historical replay and live runtime compute equivalent causal features and decisions. |
| Execution realism | Evidence that fills, non-fills, latency, spread, quote age, and cancels are modeled conservatively. |
| Protected surface | Any file, artifact, runtime behavior, broker behavior, or data action listed in `DO_NOT_TOUCH_WITHOUT_APPROVAL.md`. |
